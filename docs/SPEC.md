# Қalta — спецификация продукта

Подробные решения по логике, эргономике и дизайну с источниками — в [UX-SPEC.md](UX-SPEC.md). Здесь только границы продукта и критерии приёмки.

## Цели

Личный финансовый трекер для Казахстана: расходы и доходы, остатки на наличных и карте, месячный бюджет, долги между людьми, категории. Языки: русский, казахский, английский. Валюта: тенге. Работает офлайн; вход через Google включает синхронизацию между устройствами.

## Не-цели

- Не банк: нет интеграций с банками и платёжными системами.
- Нет общих или командных пространств: один человек, один аккаунт (но несколько устройств).
- Нет собственного сервера: статический клиент и Firebase как необязательное облако.
- Нет повторяющихся операций, push-напоминаний, бюджетов по категориям и нескольких валют (см. «Вне охвата» в UX-SPEC).

## Данные и приватность

Хранятся: операции (сумма, категория, способ оплаты, момент, заметка), долги (имя, сумма, срок, возвраты), настройки (язык, акцент, категории, бюджет, остатки). Не хранятся: пароли, номера карт и счетов. Из профиля Google используются имя или email для строки «Вы вошли как …». Аналитики и трекеров нет.

## Платформа

PWA (iOS Safari и «На экран Домой», Android Chrome, настольные браузеры). Хостинг: Firebase Hosting (`qalta-by-yerbo.web.app`); GitHub Pages остаётся запасным вариантом.

## Критерии приёмки

1. Свежая установка пуста: нет демо-операций, выдуманных остатков и бюджета.
2. Типичная запись через быструю карточку: не более 6 касаний.
3. Любое удаление и замена данных (операция, долг, категория, импорт копии) отменяется в течение 6 секунд.
4. Повторное нажатие «Сохранить» не создаёт дубликат; история сортируется по реальному моменту операции.
5. Долг можно записать на любое имя; возвраты не превышают остаток.
6. Баланс счёта равен введённому остатку плюс операции после него.
7. Тема «Авто» следует системной; тёмная и светлая проходят WCAG 2.2 AA по контрасту (проверяется тестом).
8. Приложение запускается без сети и сохраняет данные между запусками.
9. Все диалоги модальны: фокус внутри, фон недоступен, Escape и «назад» закрывают верхний слой.
10. Приложение работает без Firebase (`QALTA_FIREBASE_CONFIG = null`).
11. Нет секретов в репозитории; данные извне проходят проверку (`sanitizeState`, `Sync.clean`).
