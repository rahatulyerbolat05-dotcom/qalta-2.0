# Сеть категорий: отчёт обучения

Сгенерировано `node tools/ml/train.js`, руками не править. Данные — только словарь `tools/ml/lexicon.js` (1160 слов и названий) и фразы из него с шумом. Реальных записей в обучении нет, поэтому цифры ниже — проверка на сгенерированных фразах, а не точность на ваших данных.

- Сеть: хэшированные слова, начала слов и символьные 3- и 4-граммы → 4096 ячеек × 16 → скрытый слой 32 (ReLU) → 26 категорий; вложения в int8.
- Файл модели: 105 КБ (`cat-model.json`), обучение и проверка 60 с, зерно 20261007.
- «Как решает приложение» — вся цепочка `CAT.suggest` со встроенными категориями и без истории: сама она выбирает категорию, только если во фразе есть слово, которому сеть училась именно для этой категории, или название категории.

## Результаты

Среднее по трём разбиениям, в скобках — разброс.

- Незнакомые слова, сеть сама по себе: верная категория первой — 33,9 % (31,1–38,5), среди первых трёх — 47,8 % (45,2–51,6).
- Незнакомые слова, сеть сама по себе: уверена (p ≥ 0,8) в 79,1 % (77,5–81,1) фраз, но права из них лишь в 39,3 % (36,0–43,7). Поэтому сама она не выбирает.
- Незнакомые слова, как решает приложение: выбирает само в 24,5 % (22,0–29,4) фраз и право в 88,1 % (84,8–91,4) из них; верная категория среди первых трёх кнопок в 54,4 % (52,4–57,8).
- Знакомые слова в новых фразах и с опечатками: сеть — первой 95,3 % (95,0–95,5); приложение выбирает само в 84,0 % (83,4–84,9) и право в 99,5 % (99,4–99,6).
- Поставляемая сеть на своих словах: верная категория первой — 94,4 %.
