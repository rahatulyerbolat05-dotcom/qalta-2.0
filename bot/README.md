# Telegram-бот Қalta

Бот принимает фразу («кофе 2800», «вчера такси 1 500 наличными», «+420 000 зарплата») и записывает операцию в ваши данные Firestore. Приложение видит её обычной синхронизацией. Разбор фразы и категории делают те же `src/parse.js` и `src/cat.js` с нейросетью, что и в приложении.

## Сколько стоит

Ничего, в пределах бесплатных лимитов:

| Что | Где | Бесплатный лимит |
|---|---|---|
| Бот | Cloudflare Workers, Free | 100 000 запросов в сутки, 10 мс процессора на запрос |
| Данные | Firebase Spark (бесплатный тариф) | 50 000 чтений, 20 000 записей в сутки |
| Telegram Bot API | Telegram | бесплатно |

Тариф Blaze и облачные функции Firebase не нужны. Платных ИИ-сервисов нет: нейросеть лежит внутри бота.

На одно сообщение уходит примерно 3–4 чтения и 2 записи Firestore. Отчёт за месяц читает операции месяца. Для одного человека или семьи это далеко от лимитов.

## Как это устроено

- `worker.js` — точка входа Cloudflare. Проверяет секрет вебхука, сначала выполняет работу, потом отвечает Telegram «ok». Если Worker остановят на полпути, Telegram пришлёт обновление ещё раз. Номер операции берётся из самого сообщения, поэтому повтор перезапишет ту же запись, а не создаст вторую.
- `core.js` — сам бот, не зависит от хостинга. Привязка по одноразовому коду, запись, отмена, смена категории кнопками, вопрос, если категория неясна, `/month`, `/today`, `/undo`, `/stop`.
- `firestore.js` — Firestore через REST и сервисный аккаунт (RS256 JWT, WebCrypto).
- `telegram.js` — три вызова Bot API.
- Данные бота: `botLinks/{код}` создаёт приложение (правила разрешают только создание и только для своего uid). `botUsers/tg_{id}` — связь и состояние бота, клиентам закрыто. Операции пишутся в `users/{uid}/ops` с `_d: "tg"`, как с любого другого устройства.
- Время считается в часовом поясе человека: его передаёт приложение при привязке, обычно Asia/Almaty. «Вчера» в 01:30 ночи — это действительно вчера по Алматы, а не по UTC.

Проверка: `npm test` (тесты `tests/bot*.test.js` и `tests/tg-link.test.js`).

## Как запустить (один раз, всё в вашем терминале)

Токены и ключи никому не пересылайте, в том числе в чат с ассистентом.

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и username, например `qalta_wallet_bot`. Сохраните токен.
2. **Ключ Firebase.** Консоль Firebase → ⚙ Настройки проекта → Service accounts → Generate new private key. Скачается JSON-файл. Храните его вне папки проекта.
3. **Правила Firestore.** Опубликуйте `firestore.rules` из корня проекта: в них новое правило для `botLinks`.
4. **Cloudflare.** Зарегистрируйтесь на cloudflare.com (бесплатно), затем в папке `bot`:

```powershell
cd D:\qalta-app\bot
npx wrangler login
npx wrangler secret put TG_TOKEN
Get-Content C:\путь\к\ключу.json -Raw | npx wrangler secret put FIREBASE_SA
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
npx wrangler secret put TG_SECRET
npx wrangler deploy
```

На `TG_TOKEN` вставьте токен из шага 1. Для `TG_SECRET` вставьте строку, которую напечатала команда `node -e`. `deploy` покажет адрес вида `https://qalta-bot.<имя>.workers.dev`.

5. **Вебхук.** В том же терминале, со своим токеном и тем же секретом:

```powershell
$env:TG_TOKEN="токен"; $env:TG_SECRET="секрет"; node set-webhook.js https://qalta-bot.<имя>.workers.dev
```

6. **Приложение.** В `firebase-config.js` впишите username бота: `window.QALTA_TELEGRAM_BOT = "qalta_wallet_bot";`. После выкладки в Настройках, при входе через Google, появится «Telegram-бот → Подключить».
